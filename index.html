    Whiteboard 2.0 — Help Manual

    Select — Click to select images, text, or shapes. Drag to move. Resize via corner handles.
    Pen — Freehand drawing. Choose color from palette.
    Highlighter — Translucent highlight strokes with pulsating glow effect.
    Eraser — Erase pen strokes, highlights, and text. Does not affect images or background.
    Hand / Pan — Drag to pan around the board without drawing.
    Text — Click to create a text box. Use the floating bar for heading, bold, size, and text color. Adding text or an image switches to Select automatically.
    Brush Size — Slide the size control (2–100) to resize the pen or highlighter brush.
    Color Palette — Crayola 12-pack colors. Affects pen and text.
    Shapes — Add Triangle, Circle, Square, Rectangle, Parallelogram, Rhombus, Pentagon, Hexagon, Straight Line, or Custom Draw.
    Paste — Paste text or upload images.
    Background — Upload a custom background image.
    Slides — Add, rename, reorder, and delete slides. Names sync live to all peers.
    Undo / Redo — Undo/Redo only affects your own changes (per slide, up to 100 steps).
    Clear Board — Erases current slide content (keeps background).
    Share — Host or join a real-time P2P session.
    Export — Export current slide as PNG or PDF, or all slides as a single PDF.
